# Morph Channel 4.0.0-alpha.1

This controlled-devnet prerelease closes the current implementation and
acceptance work in #15, #19, #56, #46 and #20. Its tag is `v4.0.0-alpha.1`,
normalizing the requested v4.0-alpha1 label to the repository's leading-v,
three-component version convention and a SemVer alpha identifier. The GitHub
release is a prerelease, with the title `Morph Channel 4.0.0-alpha.1`.

## Current implementation

CKB, one token and multiple tokens use one channel State/Vault-set
implementation and one distinct Factory rights authority. The current
descriptor-5 ordinary/CKB-conditional capability, FS/FM/FR authorizations,
compact localized rights, complete-set custody and same-path signer recovery
remain available. Retired codecs, old command paths and fallback readers are
not supported; recreate disposable development state after incompatible changes.

## Measured reduced-right budgets

The clean `bb6b764` native run completed all functional scenarios, then correctly
failed the older uniform 40M-cycle smoke ceiling on the newly exercised ten-right
update. Its two-member, one-CKB-Vault Factory had twelve precommitted rights:
two ReserveClaims and ten SponsorBudgetClaims. Measurements were:

| Changed rights | Measured cycles | Fully signed transaction bytes | Protocol witness bytes | Aggregate proof siblings | Named cycle ceiling |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 11,392,803 | 3,020 | 1,777 | 8 | 15,000,000 |
| 4 | 23,676,049 | 4,396 | 3,153 | 28 | 30,000,000 |
| 10 | 48,264,869 | 7,488 | 6,245 | 78 | 55,000,000 |

The qualified profile therefore uses a 55M outer/Factory-case ceiling with an
explicit ten-right transaction allowance. Every other native case remains at
40M and deployment at 2M per transaction. Known Factory transaction paths keep
40M or tighter named caps; the only named exception above 40M is the ten-right
path. ReducedRights additionally has an 8,192-byte witness, 96 aggregate-sibling
and 10,000-byte transaction bound. The consensus per-proof limit remains 64;
aggregate sibling counts sum all compact before/after proof pairs.

Total cycle/byte budgets are unchanged. Public evidence exports these scoped
limits instead of describing the largest cap as a universal native limit.
The failed older run is retained as a measurement; final release acceptance
uses a new committed source and a fresh run, not a relabelled old report.
These fixture limits do not qualify arbitrary assets, larger proof topologies
or the separate 70M joint-dimension VM ceiling for deployment.

## Reproduction and published artifacts

From the tagged source and pinned toolchain:

```sh
make ci
CKB_BIN=/path/to/pinned/ckb \
  OUT_DIR=target/current-protocol-e2e/alpha1-review \
  scripts/devnet-current-e2e.sh
python3 scripts/export-current-public-evidence.py \
  --run-dir target/current-protocol-e2e/alpha1-review \
  --output-dir target/alpha1-public-evidence
make package-contract-release
```

Use the documented disposable development fixtures. The runner freezes its CLI
and eight ELFs, records source provenance before building, and enforces finite
transaction/proof budgets, exact artifact assertions and source freshness.
An existing output directory or dirty/changed implementation cannot be relabelled
as a clean run.

The GitHub release attaches `morph-current-custody.tar.gz`, following the
existing capability-named deterministic bundle convention. The archive
contains eight ELFs, their manifest, the no-real-assets envelope, watch policy
and publication configuration, with internal SHA-256 checksums. Sanitized
acceptance evidence and release checksums bind the release source and artifacts;
private journals, raw signed recovery and unbroadcast authorizations are omitted.
The release notes record the actual commit, test results and artifact digests.

## Scope and remaining gates

- Only controlled no-value devnet use is admitted. The devnet xUDT issuer is a
  fixture, not a production asset implementation.
- Private artifact persistence currently requires Unix permission controls.
  Unsupported platform ACL persistence fails closed rather than claiming an
  equivalent confidentiality boundary.
- Reduced exits require precommitted claims, complete initial rights data,
  feasible payout/retained-floor geometry, valid asset Scripts and fee capacity.
  They do not unilaterally retire the last collective Factory carrier.
- Full-store signer rollback still requires an independent trusted freshness
  boundary; fsync, signatures and internal hashes do not provide it alone.
- Conditional token routing, live Morph-backed Fiber/MPP acceptance, pooled
  scheduling/RPC failover, terminal abort service tracking, cooperative terminal
  bilateral close and member changes remain separately tracked.
- Independent audit arrangements were cancelled by the user. No independent
  review/rebuild evidence is claimed; the repository's production and real-asset
  readiness gates remain unfulfilled.

The native cases qualify their actual shapes. They do not turn a two-member,
one-child-at-a-time plain-CKB Factory run into qualification of every 16-member/four-child/eight-asset
joint maximum. Expanded admission and public-network measurements remain under
#21, #22, #27 and #28.
